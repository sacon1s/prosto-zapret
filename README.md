# Zapret Pro

Улучшенная и проработанная версия **zapret-discord-youtube** (Flowseal) с автоматизацией.
Обход блокировок **Discord, YouTube и других сервисов без VPN** — через модификацию пакетов
(winws.exe + WinDivert из проекта [bol-van/zapret](https://github.com/bol-van/zapret)).

Дистрибутив — **один файл** `Zapret-Pro-1.0.0.zip`. На любом ПК:

1. Распаковать в любое место (путь без кириллицы).
2. Запустить **`1 - ВКЛЮЧИТЬ ЗАПРЕТ.bat`**, согласиться с UAC.
3. Всё. Первый запуск сам сделает: чинит драйвер WinDivert, отключает конфликтующие
   менеджеры (ZapretGUI — обратимо), подбирает рабочую стратегию (27 шт.), чинит
   **картинки Discord** (hosts-пин media-доменов на живой пул Cloudflare), ставит
   автозапуск со сторожем. Дальнейшие запуски — мгновенные.

В корне папки — всего **3 файла**:

| Файл | Что делает |
|---|---|
| `1 - ВКЛЮЧИТЬ ЗАПРЕТ.bat` | Включить обход. Первый запуск = полная автонастройка (3-5 мин), дальше — мгновенный старт + проверка |
| `2 - АВТОЗАПУСК.bat` | Переключатель: автозапуска нет → поставит на автозапуск с ПК; есть → снимет |
| `3 - ПОДБОР НАСТРОЕК.bat` | Подбор лучших настроек: перебирает все стратегии, находит рабочую и сохраняет. Запускать до включения или когда доступ пропал |

Все остальные инструменты (проверка, остановка, обновление, DNS, диагностика,
фикс картинок, полное удаление `UNINSTALL.bat` и меню `zapret.bat`) лежат в папке
**`extra\`** — они нужны редко.

Полное удаление одним файлом: `extra\UNINSTALL.bat` (снимает задачу, сторожа, winws,
пины, возвращает отключённые службы).

### Сторож (главное отличие от оригинала)

Резидентный процесс `tools\autostart.ps1` (запускается скрыто задачей «ZapretPro»):

- **winws упал → мгновенный перезапуск** сохранённой стратегии (с backoff, без циклов перезапуска);
- **раз в 3 минуты** (настраивается) проверяет доступ:
  - если доступ пропал → перебирает стратегии и **сам переключается на рабочую**, сохраняет её;
- два сторожа не конфликтуют (защита от дублей);
- всё пишется в `logs\guardian.log`.

## Файлы конфигурации

- `config.ini` — стратегия, режимы, таймауты (с комментариями).
- `lists\list-general-user.txt` — **ваши** домены, добавить в обход (по одному в строке: `example.com`).
- `lists\list-exclude-user.txt` — домены, которые обходить **не нужно**.
- `lists\ipset-exclude-user.txt` — IP/подсети, которые обходить не нужно.
- `strategies\01.txt … 22.txt` — библиотека стратегий (пересобирается из пресетов при UPDATE).
- `logs\` — журналы: `zapret.log`, `guardian.log`, `tune-report.txt`, `winws-lasterr.log`.

### Дополнительные сервисы (не только Discord/YouTube)

Режим `IPSET=1` в `config.ini` (включён по умолчанию): помимо доменных списков включается
большой список IP-подсетей заблокированных сервисов — обход применяется к ним автоматически.
Чтобы добавить свой сервис: впишите домен в `list-general-user.txt`. Отключить: `IPSET=0`.

### Игровые порты (если нужно)

`GAME_FILTER=tcp|udp|both` + диапазоны в `config.ini` — для игр с блокировками по портам
(например, некоторые тайтлы с P2P). По умолчанию выключено.

## Как это работает (коротко)

`winws.exe` перехватывает пакеты к заблокированным хостам (TCP 80/443 и UDP/QUIC, порты
голосового трафика Discord) и «путает» DPI-оборудование провайдера: отправляет фейковые
первый пакет (TLS ClientHello / QUIC Init), разбивает и дублирует пакеты, подделывает
последовательности (`fake`, `multisplit`, `fake,split2`, `syndata` + fooling `badseq/md5sig/ts`).
Контент при этом не искажается — соединение проходит как обычно. Это **не VPN**: трафик идёт
напрямую, скорость не режется туннелем.

## Если что-то перестало работать (порядок действий)

1. `CHECK.bat` — посмотреть, что именно не так.
2. `TUNE.bat` — провайдер мог изменить поведение; перебор найдёт новую рабочую стратегию.
3. `DIAGNOSTICS.bat` — проверить DNS-подмену и конфликты.
4. Если DNS-подмена → `DNS-SET.bat`, затем снова `TUNE.bat`.
5. `UPDATE.bat` — свежие стратегии и ядро с GitHub.
6. Discord **голосовой** чат? Он использует UDP — стратегии уже обрабатывают порты
   19294-19344 и 50000-50100. Если не работает — перезапустите Discord после `START.bat`.

## Картинки/превью в Discord (media.discordapp.net)

РКН бьёт по медиа-домену Discord отдельным методом: родной пул IP (162.159.x.**232**) —
«чёрная дыра», ни одна стратегия desync его не пробивает. Рабочее решение — **hosts-пин**:
домен закрепляется за соседним пулом (.**233**), который отвечает нормально, а DPI
обходится стратегией. Уже добавленные домены: `media.discordapp.net`, `images-ext-1/2`.

- **`FIX-MEDIA.bat`** — всё в одном: подбор стратегии + hosts-пин + проверка.
- Убрать пины: `powershell -File tools\fix-media-hosts.ps1 -Action remove`
- Если Cloudflare сменит пулы и картинки снова отвалятся — запустите `FIX-MEDIA.bat` заново.

## Важные замечания

- **Конфликт с ZapretGUI**: если у вас установлена оболочка ZapretGUI (её служба видна в
  `DIAGNOSTICS.bat`), она будет убивать winws, запущенный этим набором, — два менеджера
  одновременно работать не могут. Решение: `TAKE-CONTROL.bat` отключает её службу и запускает
  наш обход под управлением сторожа. Откат в любую минуту: `RESTORE-ZAPRETGUI.bat`.
- **Старые установки zapret**: запущенный `winws.exe` другой копии будет остановлен при
  запуске (два экземпляра не могут делить WinDivert). Отключите автозапуск старой версии.
- Требуются **права администратора** (драйвер WinDivert). Все .bat сами запрашивают UAC.
- Windows 10/11 x64. Антивирусы могут ругаться на WinDivert — это ложное срабатывание,
  драйвер подписан и используется множеством сетевых утилит.
- Инструмент для восстановления доступа к легитимным сервисам. Используйте на свой риск.
